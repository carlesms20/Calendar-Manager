# Agente de Agenda

Asistente personal en Telegram conectado con Bitrix24 para gestión de tareas y calendario.

## Stack
- Python 3.13
- aiogram (Telegram bot)
- Google Gemini (LLM)

## Setup
1. Instalar dependencias: `pip install -r requirements.txt`
2. Crear archivo `.env` con:
API_BOT=tu_token_de_telegram
API_GEMINI=tu_api_key_de_gemini
3. Ejecutar: `python bot.py`
